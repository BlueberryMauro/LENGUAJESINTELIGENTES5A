# Lenguajes Inteligentes - 5°A

Repositorio de prácticas de la materia **Lenguajes Inteligentes (5° Semestre - Grupo A)**.

---

## 📁 Estructura del Proyecto

El repositorio está organizado en carpetas según el lenguaje y tipo de práctica:

```text
LENGUAJESINTELIGENTES5A/
│
├── Prolog/             # Prácticas en SWI-Prolog (.pl)
├── Python/             # Notebooks de Jupyter en Python (.ipynb)
├── Prolog_Python/      # Práctica de integración entre Prolog y Python
└── README.md
```

---

## 📜 Contenido por Carpeta

### 🔹 1. `Prolog/`
Prácticas de lógica computacional y sistemas expertos en Prolog:
* **Práctica 1:** `PROLOG_COMENTARIOS_PRACTICA#1.pl` — Sintaxis y comentarios en Prolog.
* **Práctica 2:** `PROLOG_ATOMOS_PRACTICA#2.pl` — Átomos y relaciones básicas.
* **Práctica 3:** `PROLOG_NUMEROS_PRACTICA#3.pl` — Manejo y evaluación de números.
* **Práctica 4:** `PROLOG_NUMEROS_PRACTICA#4.pl` — Reglas numéricas y predicados.
* **Práctica 5:** `PROLOG_OPERADORES_ARITMETICOS_PRACTICA#5.pl` — Operadores aritméticos.
* **Práctica 6:** `PROLOG_OPERACIONES_RELACIONALES_PRACTICA#6.pl` — Operaciones y comparaciones relacionales.
* **Práctica 7:** `PROLOG_OPERADORES_LOGICOS_PRACTICA#7.pl` — Operadores lógicos.
* **Práctica 8:** `PROLOG_SISTEMA_EXPERTO_DE_CARROS#8.pl` — Sistema experto de diagnóstico vehicular.
* **Práctica 9:** `PROLOG_SISTEMA_EXPERTO_DE_ANIMALES_MAMIFEROS#9.pl` — Sistema experto para clasificación de animales mamíferos.

---

### 🔹 2. `Python/`
Notebooks de Python con fundamentos y procesamiento digital de imágenes:
* **Práctica 1:** `PYTHON_FUNDAMENTOS_PRACTICA1.ipynb` — Fundamentos de programación en Python.
* **Práctica 2:** `PYTHON_FUNDAMENTOS_PRACTICA#2.ipynb` — Estructuras y fundamentos avanzados.
* **Práctica 3:** `PYTHON_IMAGENES(OPERADORES)_PRACTICA#3.ipynb` — Operadores y manipulación de imágenes.
* **Práctica 4:** `PYTHON_IMAGENES_PRACTICA4.ipynb` — Filtros y transformaciones en imágenes.
* **Práctica 5:** `PYTHON_IMAGENES_PRACTICA5.ipynb` — Procesamiento y operaciones morfológicas / canales.
* **Práctica 6:** `PYTHON_IMAGENES_PRACTICA6.ipynb` — Segmentación y análisis visual.
* **Práctica 7:** `PYTHON_IMAGENES_PRACTICA7.ipynb` — Técnicas adicionales de tratamiento de imágenes.

---

### 🔹 3. `Prolog_Python/`
Práctica integral conectando el motor de inferencia de Prolog con una interfaz en Python:
* **`animales.pl`:** Base de conocimiento de reglas y hechos zoológicos.
* **`PROLOG_PYTHON_SE_ANIMALES_PRACTICA#10.ipynb`:** Interfaz e inferencia del sistema experto combinando Python y Prolog (PySwip).
